# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Contact the
project maintainer privately with a description, reproduction steps, affected
files or versions, and the potential impact.

Please allow reasonable time for investigation and remediation before public
disclosure. Do not include credentials, tokens, private datasets, or other
sensitive information in reports or pull requests.

## Scope

This project is currently research software. CI and local tooling must not
require secrets for ordinary development, and generated experiment artifacts
must not be committed unless explicitly reviewed.
